# 嘉立创 PCB 布局布线 Skill

简体中文 | [English](README.en.md)

这是面向 AI 代理的嘉立创 EDA PCB 工程执行规则。当前版本为 **5.4.0**。它把已确认原理图直接落实为可生产 PCB，重点处理板框、功能分区、器件朝向、布局、显式布线、铺铜、丝印、检查和生产交付，而不是重新怀疑或审查已经确认的电路设计。

## 核心原则

- 原理图是已批准输入；读取 PCB 对象是为了布局和走线，不是重新选型或翻查数据手册。
- 先形成真实板上进展，再做与当前动作直接相关的局部验证。
- 布局围绕供电回路、信号链、回流路径、接口可达性、装配面和机械边界展开。
- 大电流区域在不破坏回流和隔离的前提下优先使用铜皮或宽铜区，不用大量细线代替可铺铜区域。
- 不使用自动布线；显式规划走线，遇到拥塞先调整器件位置和朝向。
- DRC 是必须执行的 PCB 阶段门：布局、关键/整板布线、重铺铜和最终导出前分别检查，但不在每颗器件或每根走线后重复整板扫描。
- 跨组件重叠必须立即修正；同网焊盘间距、可信库封装内部报告及施工期未布线只按明确条件豁免，并保留原始报告与理由。
- 普通组件默认保持未锁定；完整 PCB 收尾默认清除全部组件位号丝印显示，同时保留 `Designator` 身份属性、BOM 关联及所有功能文字。
- 丝印必须在真实缩放和制造约束下可读，接口名称、针序和网络说明优先于无意义的器件位号。
- 中途收到用户有效修改时，将其并入最新设计并继续执行，不回退到旧计划。

完整规则、阶段门、工具路由和验收条件见 [SKILL.md](SKILL.md)。按任务再加载 `references/` 和 `templates/`，不要把所有参考资料一次性塞入上下文。

## 与其他组件的分工

| 组件 | 责任 |
| --- | --- |
| `easyeda-pcb-layout-routing` | PCB 工程决策、执行顺序和验收标准 |
| `easyeda-pcb-mcp` | 对当前嘉立创 PCB 文档执行类型化读写和独立读回 |
| `easyeda-api` | Bridge、Gateway、窗口身份、协议和通用公开 API |
| `easyeda-schematic-net-fanout` | 原理图设计、ECO 和电路表达 |
| `easyeda-eprj3` | 离线 `.eprj3` 工程生成与格式校验 |

## 使用方式

将本目录作为 AgentDock Skill 或其他支持 `SKILL.md` 的代理技能安装。代理在以下场景应加载本 Skill：

- 根据已完成原理图开始画 PCB。
- 继续现有 PCB 的布局、布线、铺铜或丝印。
- 检查当前 PCB 是否满足用户给定的布局和装配约束。
- 在工具能力不足时，把稳定经验反馈到 Skill 或 MCP，而不是停止板上任务。

该仓库本身不包含自动布线器，也不会替代工程师对安全、电流、机械和制造结果的最终确认。
