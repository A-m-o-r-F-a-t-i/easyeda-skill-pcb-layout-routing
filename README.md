# EasyEDA PCB Layout/Routing Skill 6.0.1

面向已确认原理图的 PCB 设计 Skill。MCP 优先封装常见操作，AI 自主决定布局、显式路径和分析时机。

依赖 PCB MCP 3.0.1。元件/封装/朝向/网络总览、大批量操作、整体与局部 SVG 属于默认工作方式，所有常规坐标默认使用 mil，无固定准备链和设计审批。

入口：[SKILL.md](SKILL.md)。操作示例：[operation-recipes.md](references/operation-recipes.md)。开发验证：[verification-contract.md](references/verification-contract.md)。

英文：[README.en.md](README.en.md)。运行 `node --test tests/*.test.mjs` 检查文档与示例；真实 PCB 效果需要独立设计验证。
