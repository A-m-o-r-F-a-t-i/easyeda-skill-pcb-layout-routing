# 完成 PCB 后的检查与导出

适用 `approved_schematic`。检查对象是画出的 PCB 和生产文件，不是重新审查已确认原理图、选型、引脚定义、器件性能、磁气隙或封装高度。未委托的电路审查不加入放行条件。

## 检查时机

普通阶段保存用 `save:true, runDrc:false`，但整板不能只在收尾检查。布局成形且正式布线前完成 `LAYOUT_DRC`，关键/整板布线节点完成 `ROUTING_DRC`，重铺实际铜后完成 `POUR_DRC`，最终丝印、清理和保存后、任何生产文件导出前完成 `FINAL_DRC`。单颗器件、单根线或每一小批写入后不重复整板检查。

## 最终检查范围

| 项目 | 完成标准 |
| --- | --- |
| 导入一致性 | PCB 器件/焊盘网络与已确认原理图同步；比较是查导入，不判断原针序是否合理 |
| 真实连接 | 应布网络已接通，无错网或未处理短路；根据原生连接信息和实际铜检查具体异常 |
| DRC | 四个阶段门按需完成；最终无阻断/未决项，未布线为零；允许豁免保留原始报告和理由，失败/空返回不能冒充通过 |
| 回路 | 供电去程与返回、局部开关回路、Kelvin、参考地及关键换层连续；宽铜出口和窄颈符合采用的布线规则 |
| 几何与可用性 | 给定板框、孔槽、禁区、面别、接口朝外、主体不越界与功能丝印已落实 |
| 文件 | 来源于最终保存状态，层数、板框、孔槽、单位、坐标原点、面别与实际对象一致 |

工具自带的独立写入读回可复用，不要求再逐颗 pinmap 全量复核。原生检查能覆盖的结果直接采信；自制审计器不支持某种复杂铜时，只在确实缺少连接证据的具体区域补查，不自动升级成全板阻断。实际已知问题不得通过改网络、删必要对象、隐藏或放宽规则消除。

## DRC 与视觉

`pcb_save_and_drc`区分保存结果、DRC 是否执行和错误明细。分类树按诊断叶节点统计，读取失败不是零错误。每次结果按 [DRC 策略](drc-policy.md)分成 `blocking`、`waived`、`unresolved`：跨组件物理重叠优先阻断，同网间距不能覆盖重叠；可信封装内部报告和施工期未布线只有满足条件才豁免。原生报告仍有豁免项时不得称“零错误”。修复后复查受影响阶段和最终状态。

几何 SVG 用于整体排布，视口 PNG 用于当前字形和遮挡。不要为凑多种证据重复截图，不要求补齐每颗器件 3D 模型。尺寸图、面别及已有封装方向与用户要求一致即可完成本任务范围检查；未作高度/气隙实测不宣称已验证，但也不创建额外验证任务。

## 导出

`pcb_export`支持：`backup`、`gerber`、`bom`、`pick_place`、`test_point`、`netlist`、`ipc_d_356a`、`dsn`。只导出任务需要的种类。使用新的输出路径，不覆盖旧交付、不自动上传、不下单付款。

备份包含真实工程，不用检查点或哈希代替。Gerber/钻孔检查层、板框和孔槽；BOM 沿用源器件的料号、数值、数量与 DNP，不另做选型审查；贴片坐标与实际位号、面、角度一致。文件实际生成后核对内容，不凭 ZIP/XLSX 非空宣称完成。

导出期间若设计改变，只重新生成受影响的最终文件，不重审电路。阶段报告采用：

- `READY_FOR_FAB`：PCB 制造检查与裸板文件完成，不代表电路功能或样机性能认证。
- `READY_FOR_ASSEMBLY`：同时完成 BOM、贴片坐标与给定装配方向核对，不代表高度、磁气隙等实测。
- `NOT_READY`：存在具体未完成的 PCB 连接、制造错误或文件缺失，列实际对象/文件，不罗列未委托的电气审查。
