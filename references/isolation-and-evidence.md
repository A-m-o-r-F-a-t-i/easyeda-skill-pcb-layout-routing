# 隔离实验与验证证据

## 范围与发布

用户指定废弃工程为试验板时，只在该工程的精确窗口和PCB内建立测试对象。其他线程的工程属于排除对象，不能为了获取画布或连接而切换它的浏览器焦点、当前PCB、服务或MCP版本。目标尚未连接时继续离线验证，真实读写保留待测，不能使用模拟PCB替代真实测试结论。

先复制工具源码并固定基线版本，新增反例在旧版复现，再修复并执行完整回归。独立MCP进程使用独立名称、版本目录及工程允许列表。测试通过后发布新包，保留旧运行实例和回退版本，不对正在工作中的线程热切换。Skill正文更新可独立安装，但必须说明其中新工具依赖的MCP版本。

## 真实试验顺序

1. 读取窗口/工程/PCB身份、当前对象和需要恢复的字段。全局服务或浏览器状态不作为可随意修改的试验对象。
2. 先做只读状态、能力、pins、属性、区域查询、规则和覆铜数据测试。入口探测与实际调用分别记录。
3. 在用户允许的试验区域创建有明确标记的独立文字，读回、修改、重复执行验证幂等，再用真实旧值删除，确认测试对象已清理。
4. 通过故意陈旧expected或错误目标UUID测试拒绝路径。反例必须在原生修改发起前失败，不能先写错再把事后检测当保护成功。
5. 约束组和实时DRC采用创建/修改/恢复的可回退闭环。ECO、删器件和覆铜可能影响更广范围，先保存适用的原生可恢复副本，不能以JSON检查快照替代原生工程备份。
6. 比较前后完整、同单位、同身份的数据，核对测试对象清理和无关字段。可读性需要真实顶底画布/制造预览；代码数据不能代替这些验收。

## 证据等级

| 标记 | 实际证据 | 不能替代 |
| --- | --- | --- |
| DOC | 官方签名、源码和提示词审查 | 运行成功 |
| UNIT | 合成数据、异常注入、mock客户端自动测试 | 真实客户端API兼容性 |
| MCP_PROTOCOL | 已安装进程的schema发现和stdio调用 | EDA写入成功 |
| LIVE_RO | 精确真实工程只读调用和结果 | 修改/保存路径 |
| LIVE_RW | 真实操作、独立读回、清理/恢复 | 电气和视觉验收 |
| VISUAL | 实际画布、3D、制造图核对 | 实板印刷效果 |
| PHYSICAL | 实物测量或使用测试 | 未覆盖工艺/批次 |

测试报告按方法及样本说明，不把关键词检查写成模型行为测评。提示词桌面演练可以验证规则之间的矛盾和具体执行选择，不能宣称所有模型都能稳定遵循。

## 新增提示词反例

| 案例 | 输入或状态 | 应采取的动作 |
| --- | --- | --- |
| P19 并行实验 | 仅生产窗口在线，试验工程未连接 | 保留准确范围，暂停试验板读写；继续离线测试，不抢前台。 |
| P20 API占位 | 方法存在但DRC返回false或状态不符 | 记录操作失败，不能报告DRC已启动。 |
| P21 仅属性字 | strings=0，attributes有可见丝印 | 执行属性检查，不能报告没有文字。 |
| P22 人工移位 | 预读后用户改坐标/换页 | 下一原生写前复核并拒绝陈旧计划，重新读取。 |
| P23 更大字体 | 名义字号达阈值但实板反馈看不清 | 调整信息带/分行/字号并做视觉检查，不引用极限数字代替可读性。 |
| P24 用户删位号 | 用户明确去除C27类位号 | 隐藏相应属性字，保留器件身份，不用默认保留规则阻止。 |
| P25 部分ECO | 源端存在被明确排除的修改，工具只能整板导入 | 暂缓整板导入或使用已验证的选择性途径，不能假称跳过。 |
| P26 纯丝印验收 | 检查快照缺少部分铜类型 | 报告实际比较范围，不能报告所有电气内容未变。 |
| P27 重铺旧数据 | 返回无新填充但读取仍有旧Poured | 保留本次重建未验证状态，检查operationResults和填充关联。 |

这些案例补充已有P01～P18。每次实验填写实际执行等级与结果，未测试项保持待测。
