# FOC 布局与回路提示

采用 approved_schematic，沿用原电路的相序、采样极性、器件参数和控制连接。这里只组织空间、路径与铜，不重新审查死区、增益、气隙、磁钢或封装高度。

每相从实际网络识别上下管、开关节点、相线端、本地旁路、驱动和自举。相似模块可复用相对位置，再按板边、孔槽和端点调整，也可一次提交三相或整板布局。

| 角色 | 空间与连接考虑 |
| --- | --- |
| 入口储能 | 随入口与保护链安排，不占敏感信号通道 |
| 半桥本地母线旁路 | 电容正端、上下管和负端返回形成紧凑换流回路 |
| 驱动去耦、自举 | 跟随服务芯片和实际参考端，去程与返回一起短 |
| 栅极链路 | 驱动、栅阻、MOS 栅极及源极参考返回一起安排 |
| 电流采样 | 主电流宽铜与 Kelvin 取样支路分开，取样从对应焊盘引出 |
| ADC 滤波 | 放大器输出后的串阻、电容和 ADC 端形成局部组，输入滤波服务输入端 |

同一网络上的电容可能承担不同角色，不能全部挪到同一个区域。主电流支路即使名称包含 SENSE 也不能按小信号走线。

中心传感器沿用用户给定面与位置。没有提供敏感中心偏移时保留封装原点含义，不伪称已验证测量精度，也不追加磁路调查。

MCU 与驱动器朝向兼顾整组 PWM、采样与通信出口。必要时重排局部模块，不用零散过孔和反复绕行固化不良通道。地参考和功率返回避免侵入 Kelvin 与模拟采样支路。

相线端使用实际连接器或已授权专用焊盘，内部 MOS 焊盘不替代外接端。根据已有电流与工艺要求安排宽铜、铜颈及换层阵列。DRC 和局部分析由 AI 按当前结果决定，无固定阶段审批，无默认上电或加载测试。
