# FOC 布局与回路提示

　　采用 approved_schematic，沿用原电路的相序、采样极性、器件参数和控制连接。这里只组织空间、路径与铜，不重新审查死区、增益、气隙、磁钢或封装高度。

## 功率级与服务对象

　　每相从实际焊盘关系识别上下管、开关节点、相线端、本地旁路、驱动和自举。相似模块可复用相对位置，再按板边、孔槽和端点调整，也可一次提交三相或整板布局。

| 角色 | 空间与连接考虑 |
| --- | --- |
| 入口储能 | 随入口与保护链安排，不占敏感信号通道 |
| 半桥本地母线旁路 | 电容正端、上下管和负端返回形成紧凑换流回路 |
| 驱动去耦、自举 | 跟随服务芯片和实际参考端，去程与返回一起短 |
| 栅极链路 | 驱动、栅阻、MOS 栅极及源极参考返回一起安排 |
| 电流采样 | 主电流宽铜与 Kelvin 取样支路分开，取样从对应焊盘引出 |
| ADC 滤波 | 放大器输出后的串阻、电容和 ADC 端形成局部组，输入滤波服务输入端 |

　　同一网络上的电容可能承担不同角色，不能全部挪到同一个区域。名称含 SENSE 的网络可能同时承载主电流、采样和驱动参考，分别追踪对应焊盘与支路；小孔存在于检测分支时，不能认定主电流全部经过该孔。

## 三相与采样联合安排

　　MCU 与驱动器朝向兼顾整组 PWM、采样与通信出口。每相采用相同的检查对象：本地换流回路、栅极去程与参考返回、相线输出、采样取点至输入端、输出滤波至 ADC。逐相比较路径与换层，检查近端改善是否挤占远端通道。

　　允许满足孔槽与接口要求的不对称布局，不强求三相等长或完全相同坐标。部分 MOS 输出朝向外接焊盘只能说明该出口改善，不能代替对驱动、采样和母线返回的整体判断。反复绕行时重排相关器件组，避免用零散换层固化通道问题。

　　主电流宽铜、检测支路和源极参考分别安排，地参考与功率返回避免侵入 Kelvin 和模拟采样通道。普通参考地孔不能直接代替高边驱动的开关参考返回。

## 固定对象与收尾

　　中心传感器沿用用户给定面与位置。没有提供敏感中心偏移时保留封装原点含义，不伪称已验证测量精度，也不追加磁路调查。

　　相线端使用实际连接器或已授权专用焊盘，内部 MOS 焊盘不替代外接端。根据已有电流与工艺安排宽铜、铜颈和必要换层阵列，按[布局与布线](../placement-routing-closure.md)处理候选孔位和定向刷新。DRC、几何连通及实际上电表现分别报告，无固定阶段审批，无默认上电或加载测试。
