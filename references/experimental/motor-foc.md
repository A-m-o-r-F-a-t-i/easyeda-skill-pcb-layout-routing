# FOC PCB：已有电路的布局与回路速查

适用 `approved_schematic`。这是布局知识，不是 FOC 电路、固件或电机性能审查。沿用原理图的器件、参数、相序、采样极性和控制连接；不重新论证耐压、驱动能力、死区、ADC 时序、采样增益或磁钢/气隙/封装高度。不因这些资料未提供而暂停 PCB，也不留待交付前补审。

## 先把现有连接分成可放置的小模块

每相只需辨认当前网络中的上下管、开关节点、相线端、本地旁路、自举与驱动路径。有采样电阻的相，再识别主电流和 Kelvin 支路。使用已有原理图分区、网络和焊盘坐标，数据已有就不重复逐器件读取；不查手册确认原电路对错。

三相拓扑相同可复用模块排列，再按实际板边、端点和孔位调整。不是先写完整拓扑审查报告，而是读完一组就移动一组，再试布最拥挤的铜通道。

## 功率与电容

| 已有器件角色 | 放置与连接 |
| --- | --- |
| 入口储能 | 靠入口与保护链，不挤占敏感区 |
| 半桥本地母线旁路 | 紧靠对应上下管，电容正端→高边→低边→电容负端的换流路径短而宽 |
| 驱动去耦 | 靠驱动电源/参考端，供电去程与返回同时短 |
| 自举电容及二极管 | 围绕原网表的 BST/BOOT 与开关参考端就近布置 |
| 稳压与模拟去耦 | 跟随服务芯片，不散放到剩余空隙 |

同一网络不代表所有电容都能放在一起，也不需要复核总容量或每颗容值。入口储能离某相较远不是布局错误，重点是该相现有本地旁路和返回路径是否被拉长。缺少某功能器件不在 PCB 阶段擅自添加。

## 栅极与自举回路

驱动输出→已有栅极电阻→MOS 栅极，与对应源极/参考端返回共同规划。电阻靠服务对象，不把栅极线绕过大块开关铜。自举回路按既有连接走线，不重新审查充电机制或最大占空比。

关键外围优先和驱动器同面；确需跨面时把去程、返回和过孔放近，保持回路紧凑，不启动跨面电气/高度审批。普通布局保持可调整，走不顺就整体旋转该小模块。

## 电流采样

相内采样的电阻两侧都可能承载相电流，不能因为网络名含 SENSE 就当作小信号。主电流从采样电阻功率焊盘宽铜进入、离开；取样支路从对应焊盘单独成对引向放大器，不在主电流铜中途随意取点，不承担主电流。

放大器输入侧朝采样电阻；若输出经串阻后，与滤波电容及 MCU ADC 同网，串阻、电容和 ADC 脚形成 ADC 输入局部组，不能把串阻按放大器邻近关系放远。放大器输入 RC、参考和去耦围绕其各自服务端摆放。只优化已有网络的空间和铜路径，不重新计算增益、ADC 范围、RC 时间常数或采样窗口。

## 传感器与控制

中心传感器按用户给定的安装面、轴线和偏移直接落位。项目已有敏感中心偏移就使用；未给偏移时以现有封装定位中心作为可调整布局基准，不查磁钢、气隙、偏心或高度，不把暂定位置宣称为测量性能验证。

电感、主要大电流路径和开关节点远离给定敏感区。MCU 与驱动器的相对位置、朝向先试通整组 PWM，再兼顾 ADC、SPI 与接口出口；尚未试通前不大量落功率铜。端点距离近而实际线长大时先修扇出、换层和走廊，不一律归咎于摆放。主地参考尽量连续，不让功率返回挤入模拟取样支路。

## 相线端与收尾

U/V/W 应使用项目要求的真实连接器或专用接线焊盘，内部 MOS 焊盘不能代替外接相线端点。已授权的独立端点直接创建并绑定原网络，已有端点不能重复创建。沿用原相序和采样极性，不交换网络迁就布局。

相线端子的镀通或表贴形式与半桥、分流器、主铜同步决定，沿用用户约束，不默认强制某种形式。镀通端子自带层间连接，不计作 Via；表贴端子的换层孔应与功率通道一起预留。按当前电流等级/布线规则预留宽铜、铜颈及并联换层孔。三相功率模块成体系布局完成、准备正式布线前做 `LAYOUT_DRC`，立即修正跨组件焊盘/实体重叠；三相关键铜和整板布线节点做 `ROUTING_DRC`；重铺实际铜后做 `POUR_DRC`；丝印收尾和导出前做 `FINAL_DRC`。单个候选模块每次移动后不重复整板 DRC，也不安排上电、加载或电机控制测试。
