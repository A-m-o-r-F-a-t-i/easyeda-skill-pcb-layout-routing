# 专项资料按职责加载

已确认原理图到 PCB 使用 approved_schematic。识别到 FOC、功率或高速器件不是启动电路复审的理由，也不自动建立仿真、样机测试、参数预算或额定值证据表。

| 场景 | 使用方式 |
| --- | --- |
| 三相功率板布局 | 按需读 [FOC 布局速查](motor-foc.md)，只处理现有半桥、自举、去耦、采样和回流的空间关系 |
| 用户明确委托大功率专项分析 | 才读 [大功率专题](high-power.md)；既有电路画板不执行其中选型、绝缘认证、热或故障试验要求 |
| 用户明确委托高速通道设计/验证 | 才读 [高速专题](high-speed.md)；普通画板沿用给定叠层/阻抗/长度约束，不自动生成全套仿真任务 |

专题的器件性能和试验内容不作为默认 PCB 布局前提或最终额外阻断。已给定的隔离、参考面、禁布和制造规则照做；实际 PCB 短路、间距和断网必须修复。未经测试不能宣称性能认证，但无需为这种未委托认证阻止 PCB 执行和文件交付。
