# EXPERIMENTAL：大功率PCB

**状态：试验性，尚未完成专题样板验证。** 功率大小没有统一瓦数分界，按电流、开关边沿、热和故障能量决定是否启用。基本PCB机械、制造和手工布线规则继续适用。

## 1. 必填参数

母线正常/最大/瞬态电压，持续/RMS/峰值/短路电流，开关频率与边沿，功率拓扑，器件耐压/SOA/热参数，铜厚、板厚、孔铜，散热方式、环境与温升预算，连接器和线束，储能/回生及放电方式，绝缘等级与适用标准。

这些输入缺失时，只能进行局部结构设计和空间预留。特别是孔铜只有平均值、连接器只有系列名或散热条件未知时，不能批准满载能力。

## 2. 四类回路分开规划

| 回路 | 放置与路径 | 验证对象 |
| --- | --- | --- |
| 功率换流 | 识别每个开关状态，贴近的本地母线电容、上下桥器件与返回路径形成紧凑回路 | 寄生电感、尖峰、振铃与电流瓶颈 |
| 栅极驱动 | 驱动器、栅阻、栅极和源极/专用Kelvin返回短而明确 | VGS过冲、Miller误导通、驱动地弹 |
| 小信号采样 | shunt真正两端独立取样，避开SW/栅极噪声与功率公共阻抗 | 采样偏差、共模瞬态、建立时间 |
| 储能与负载 | 电容、连接器、负载及回生路径按持续电流和能量设计 | 温升、压降、回生过压和故障关断 |

这些回路依据TI电机驱动布局资料的功率与电流采样章节组织[S1]，具体拓扑仍以所用驱动器与功率器件资料为准。

## 3. 铜与热

外层宽铜/铺铜优先承载主电流，入口、焊盘热连接、保险丝、shunt及换层阵列按实际截面检查。直流损耗采用实际长度和截面计算，PWM路径用相应RMS电流，再评估动态及集肤/邻近效应是否需要更完整模型。

SW节点只保留电流与装配所需铜，优先降低换流寄生而非无限铺大。散热区不应把噪声耦合到时钟/ADC/接口。散热焊盘所连网络取自器件资料，不能把所有EP都接GND。

通孔初筛中的孔径、铜厚与电阻可计算，但将平面导线热经验式直接套在圆柱孔壁上属于粗估，不能形成保证载流。并联过孔检查入口/出口均流及反焊盘造成的平面切割，热能力需要实际工艺与样板验证。详见 [载流参考](../current-carrying-reference.md)。

## 4. 故障与绝缘

在布局中保留限流/保险丝、过压处理、硬件关断和安全放电所需路径。保护动作中流过的电流可能与正常方向不同，检查回生和掉电情况。对电机回生不能默认电源或TVS有无限吸收能力。

明确工作电压、污染程度、材料组别、海拔、绝缘类别和标准版本后再确定爬电/电气间隙。槽、螺钉、散热器和底层铜都参与检查。涂覆、开槽或阻焊不能未经规则确认就折算成任意隔离裕量。

## 5. 验证顺序与失败处理

断电核对连接、驱动禁能与放电 → 受控限流供电核对电源和故障关断 → 在适当隔离测量条件下观察开关/采样波形 → 逐步加载检查压降、器件与铜颈温升 → 验证最大环境、持续工作与关断/回生情形。

试验出现驱动异常、温升超限、保护不动作或器件应力越界时，停止受影响功率测试，保持禁能/放电状态，修改设计后再测。不通过取消保护或直接放大限流继续试验。
