# EXPERIMENTAL：高速PCB与受控互连

**状态：试验性，尚未完成对应协议的实板SI验证。** 以边沿、互连传播延迟和协议通道要求识别高速问题，不能仅按时钟主频低就忽略。规则表中的数值应由具体接口、器件和叠层填写。

## 1. 输入与约束表

| 输入 | 必须落实的设计约束 |
| --- | --- |
| 协议版本、驱动/接收器及边沿 | 端接、AC耦合、共模和接收容限 |
| PCB叠层与介质、铜厚/粗糙度、阻焊 | 单端/差分阻抗及制造容差 |
| 芯片封装、走线、连接器、线缆 | 完整通道损耗、反射与串扰预算 |
| 时钟/数据关系 | 对内偏斜、组间时序及允许长度范围 |
| 实际参考网络与换层 | 连续回流、过孔结构和参考转换 |

不用通用的90Ω/100Ω、3W或全部等长替代具体约束。制造商计算器/场求解器的输入必须对应实际选中的叠层，不能从另一块板复制线宽间距。

## 2. 布局与参考面

按发送端、接收端、连接器、保护/终端器件确定直接通道。先预留配对走线与换层区，再排非关键外围。ESD电容和封装寄生要进入通道评估，不能仅根据静电耐受等级放置高负载保护件。

保持关键线的相邻参考面连续，避免跨参考面缝隙与反焊盘阵列形成的细颈。层转换同时规划返回电流。TI的信号调理器/USB布局资料给出参考面不连续与回流转换的示意[S1]；其中接口与距离示例仅用于对应场景。

在同一GND参考之间换层可以布置邻近回流过孔；跨不同参考电源域时需要合适的高频参考转换方案。隔离屏障不允许为了回流连续而直接短接。

## 3. 路径、过孔与长度

成对线尽量共同参考、相似过孔和相似周边环境。局部焊盘逃线可以暂时解耦，但需要检查它在整个通道中的影响，不能为持续紧耦合制造复杂折返。按指定时序预算补偿长度，避免过密蛇形自耦合使电气延迟与几何长度不一致。

过孔焊盘、反焊盘、参考转换与未使用stub一起考虑。背钻、盲埋孔或via-in-pad只有在所选工艺明确支持时使用。MCP当前显式计划仅执行贯通孔，不自动规划这些工艺。

工具逐网返回的线段长度和是库存统计，不能作为某差分对的端到端电气长度；分支、重复线、过孔与封装延迟必须另行建模。

## 4. 验证与降级

先做布局/拓扑与叠层审查，再按可靠模型执行适用的SI仿真。模型缺失的连接器、封装或线缆作为缺口记录，不能宣布完整通道通过。

样板按实际接口要求采用TDR/阻抗、眼图、误码、时序或一致性测试。测试前定义速率、电压、温度、线缆、负载和判据。没有相应仪器或模型时，交付为待SI验证的设计，并保留必要测试接入条件。
