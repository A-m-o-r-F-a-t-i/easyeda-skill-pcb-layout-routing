# 当前客户端原生数据说明

本文件只记录当前联调客户端 EasyEDA Pro 4.1.60 的已观察数据表示，不承诺旧版接口适配。常见 PCB 操作仍使用 MCP，不因为原生细节改写为 API 脚本。

- 元件引脚接口与 canonical Pad 接口可能给出不同孔字段。总览优先使用同一物理 ID 的 canonical 孔数据，来源不足时孔尺寸保持未知。表贴焊盘残留的孔字段不表示存在实际钻孔。
- POLYGON 焊盘顶点可能已经处于板坐标并包含镜像、旋转。MCP 对已识别表示不再叠加焊盘位置变换；无法确认坐标系时不绘制伪造外形，并在覆盖信息中说明缺失。
- 独立焊盘坐标与外形可能量化到 0.1 mil；ROUND 可能返回两个相等尺寸。工具报告原生读回值，不把量化误差扩大成设计容差。
- 板框使用原生 Polyline，圆形使用 CIRCLE，不用大量短线冒充。REGION 只接受当前公开枚举；客户端拒绝时返回原生错误，不静默改成其他规则或源文件重写。
- 实际铺铜填充轮廓与普通图元采用不同原生尺度。仅对已确认的 4.1.60 表示换算为统一 mil；不确定表示保留为未覆盖。重铺结果同时报告非请求铜区的实际连带变化。
- 原理图同步可能出现原生确认界面。MCP 处理唯一“应用修改”控件并读取导入前后状态；原生调用返回 true 不单独代表 PCB 已改变。当前接口不提供选择性 ECO，因此不声称跳过指定差异。
- 原生 BBox 表示图形范围，不是元件本体尺寸。body、assembly、silkscreen、nativeGraphics 和 padEnvelope 在总览中分开报告。

未知写入先查看执行回执和必要局部对象，不盲目重复创建。源代码回滚不恢复 PCB。自动化模拟写入、真实客户端只读和真实测试副本写入必须分别说明验证范围。
