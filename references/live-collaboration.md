# PCB主动交付与用户中途修改

## 1. 完成任务的默认范围

用户要求“继续画PCB”“画完”“布局布线并收尾”时，默认完成合理的缺省细节、已知功能所需布局布线、重铺、规则检查、接口/操作件丝印及保存读回。不能在电气布通后把丝印和使用标识作为额外邀约。用户明确只要求评审、局部改线或只做布局时，遵循限定范围；局部修改默认维护其相关丝印，不顺便打散其他区域。

推定从当前工程、已确认项目要求、同类成熟分区和实际器件资料建立。主动检查接线、调试、装配、极性、线束、手指/工具空间及返修便利。低影响可逆细节直接决定并做完，重要推定用短句说明。器件电流、逻辑电平、协议、绝缘和最高输入须核验，无法查明且会改变设计方向时才向用户提问。

可直接补全的例子包括：统一接口组文字层级、补每针网络与1脚标记、修正遮挡、保持已有调试口可达、为手动移动后的接口重接受影响铜。需要定向的例子包括：突破明确板框、改变层数/主功能/既有线缆针序、增加成本明显的工艺、改变安全隔离或电源架构。正常范围内的模块位置和常规标识不逐项询问。

新功能与新硬件不能只因“可能更方便”加入。已有测试点优先保证可接触并标清，新增测试结构需检查网表、BOM与空间影响。无法在确定板框内同时满足布线、插拔和可读丝印时，先给出已尝试的局部解法，再请用户决定必要的边界取舍。

## 2. 用户随时介入，计划随之更新

用户可在任何阶段移动/旋转/翻面器件、改线、增删原理图内容、修改丝印或切换页面，也可用自然语言改变优先级。下一写入批次前、收到新消息后、切页/回到目标板后、执行ECO前后和验收前读取真实状态。明确暂停或撤回指令立即停止发起相关新写入。

用户切到其他板查看时不自动把新活动板当作任务目标，保留已确认目标ID并验证。基于前台的操作不得抢走用户正在输入的属性或将键盘命令发往错误窗口。能够指定目标的只读路径优先，无法安全操作的局部区域先避让；不要求用户整个任务期间停止使用编辑器。

**字段合并**：用户刚移动的位置/面/旋转、锁定、合法铜和文字布局作为当前条件。后续改线或改值不携带过期整对象覆盖。不因预计坐标不同就恢复旧布局，也不因对象消失就自动重建。最新明确指令优先于旧方案；冲突未明的电气属性不能随意选边。

**冻结的含义**：分区冻结是模型避免无谓重排的承诺，用户仍可修改。发现人工变化时解除受影响分区的旧结论，读取并重规划，不解除全板机械限制。用户动作触犯已确定安全/机械约束时指出具体问题并给出局部修复，不能默默退回旧状态或批准错误。

正在执行的工具调用可能已部分提交，无法保证即时抢占。等返回或明确超时后读取实际对象，取消未执行旧后缀，从新状态继续。没有事务锁时用旧值断言及连续稳定读回降低冲突，不能承诺无条件实时多方并发写入。

## 3. 默认合并最新原理图有效差异

用户已经要求原理图修改并同步PCB时，协调原理图Skill读取同一目标板全部相关页，对全部最新有效差异生成ECO。最初只提到1、2项，额外3项在同板有效源端出现时默认一起合并。只有明确“其余不要同步”的排除、未完成电路、错误、跨板/跨变体或真实双边冲突需要暂缓相关项。

源端已经有效形成的新增/删除器件、换封装、改值、改名和接线变化，核查后直接通过原生ECO或对应明确能力增量应用，无需因“最初没提到”反复确认。执行时先调用`pcb_import_schematic_changes(mode="preflight")`核对关联原理图、对象计数和PCB摘要；确认源端差异表后，以该摘要调用`pcb_import_schematic_changes`。公开API没有返回类型化ECO预览，因此准备工具只提供目标和状态守卫，不能替代原理图差异审查。

| 差异 | 默认接纳方式 | 必须重验的部分 |
| --- | --- | --- |
| 电路功能不变、只改名称/位号/参数 | 更新对应字段，保留有效布局与铜 | 铜的网络名、BOM和丝印语义 |
| 用户挪动/旋转/翻面接口 | 保留新位置与面，局部重接 | 实体/插拔、网络、底面针序和丝印 |
| 源端增加/删除完整器件或支路 | 按稳定关联做ECO，处理专属对象，保留共享铜 | 新布局、端点、旧铜残留、未连接和标识 |
| 源端换封装 | 核对脚号及机械影响，保留可用位置意图 | 焊盘映射、连接、庭院、原文字是否适用 |
| 网络分裂/合并或交换脚位 | 依最新拓扑重规划受影响铜 | 意外短接、串阻旁路、回流、丝印 |
| 仅PCB安装孔、标记或机械对象 | 按PCB专属属性保留 | 机械约束，无须伪造源端元件 |
| 同一电气字段两边不同且无法裁决 | 保留现场，暂缓该依赖组并提问 | 采用方向后的两边连接表 |

读取全部差异不等于重建全板。保存必要的原生可恢复副本后应用核查过的差异，避免丢弃用户位置、层、锁定、合法铜和文字。摘要失配时重新准备，不能绕过守卫强行导入。原生导入可能保留旧线，且某些变更不可撤销，因此导入后必须重读焊盘/网络/铜/覆铜/约束/文字，按变化类型处理关联铜并更新丝印。[S1]

## 4. 依赖与验收失效

维护轻量依赖关系：器件/引脚 → 网络/串联链 → 相关铜与铺铜 → 约束与检查 → 接口和操作丝印。源端改名使文字和铜网络复核失效，换脚使连接与针序失效，移动/翻面使几何、装配、回流和标识位置失效，功率参数变化使载流与热检查失效。

新ECO或人工修改只使相关结果过期。其余已验证区域保留，更新计划不要求从头重画。冲突组以外的独立网络继续推进。源端仍在变化时重新比较，不把旧的零DRC结果作为最终版本的验收。

修改/删除仍携带完整expected，移动仍遵守copperPolicy与affectedNets。expected不匹配时，先识别有效人工修改再基于新状态重新生成；不能删掉断言让旧计划强行通过。

## 5. 收尾与使用交付

布局时就为接口文字留位置，完成电气工作后按[用户友好丝印](silkscreen-usability.md)执行完整收尾。默认用户拿到板子能够分清接口用途、逐针接线、供电角色、主从/通道、按键跳帽和必要警示。默认保留位号用于返修，用户明确要求隐藏或删除位号丝印时执行该要求，保留器件身份及BOM关联。普通接口不能仅显示CN编号。

交付报告说明实际合并的额外修改、少数关键推定、检查范围和未解决项。同步来的新增接口也在标识清单里，不要求用户再说一次“把它的丝印补上”。明确只更新Skill或分析时，不因此修改当前工程。

## 6. 工具边界与来源

## 整体ECO的实际执行边界

`pcb_import_schematic_changes`调用公开的整板`importChanges`，没有逐项排除参数，也不返回源端差异预览。PCB摘要只守卫已读取的PCB字段，不替代原理图审查。存在明确排除项、未完成源电路或未裁决冲突时，只有已验证的选择性ECO路径才能应用其余项；当前路径不能选择时暂缓该板整体导入，继续不依赖ECO的工作，先消除冲突或询问最小方向。不能声称“跳过冲突组”却执行整板导入。

同一目标板已经形成且审查有效的额外修改仍默认一起同步，不因最初只列1、2而再次索取授权。多读两遍PCB并得到一致结果仅说明这些读回字段稳定，不能扩大为源端、全工程或事务锁的保证。
