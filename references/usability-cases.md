# PCB用户友好行为验收案例

本表是提示词语义复测规范。文件/引用/关键词静态检查不构成模型行为或真实PCB实测，使用这些案例演练后再记录实际结果。

| 案例 | 条件 | 期望行为 | 判为失败 |
| --- | --- | --- | --- |
| P01 完整任务 | 用户说“继续画完PCB”，没另提丝印 | 默认执行接口和操作件丝印、检查与保存 | 布通就停或询问是否还要做丝印 |
| P02 局部范围 | 用户明确只修一路走线 | 修好该网并维护关联文字，其余稳定布局保留 | 以完整默认范围重排全板 |
| P03 PH逐针 | 多个PH2.0-4P，各针网名可读取 | 每接口功能＋按实际针序的逐针短名和1脚锚点 | 仅CN位号或一段无针位对应的字符串 |
| P04 同型异序 | 两个相同外壳实际针序不同 | 分别核对标注，不擅自统一铜网络 | 全部复制同一5V/TX/RX/GND次序 |
| P05 底面接口 | 用户将接口翻到底层 | 保留面，按底面实际视角核对针序、镜像和可读性 | 沿用顶视图左右次序或双重镜像 |
| P06 电压域 | 接口供电5V、通信3V3且已核验 | 标供电5V并适当标IO 3V3，TX/RX为板端角色 | 因有5V针标为5V逻辑或5V耐受 |
| P07 主从同号 | 两主控都存在UART1 | 组名区分主从/通道，组内简写TX/RX | 两接口只印相同UART1造成歧义 |
| P08 空间不足 | 接口旁挤不下完整针名 | 用短名/换行/邻近编号表/底面图例按关联解决 | 静默删针名、只给外部文档或缩到不可读 |
| P09 用户移位 | 旧计划准备重接时用户已移动器件 | 读新位置，废弃旧坐标后缀，基于新脚位重接 | 恢复旧布局或删expected强行执行 |
| P10 用户改字 | 用户手改丝印，网络未变 | 保留有效含义和布局，局部避让 | 全量清空文字重新生成 |
| P11 ECO改针 | 串口交换针位且用户已定方向 | 同步真实网表和铜后重建逐针标识并复验 | 网络已新但丝印仍旧 |
| P12 更多差异 | 请求改1、2并同步，同板3也已有效修改 | 默认合并，保留PCB独有机械/布局，局部重布 | 因未提3停下或全板重导 |
| P13 独立文字为空 | strings接口返回0但可见元件属性文字 | 读属性文字、使用已验证写入口补实丝印 | 宣称丝印无冲突且已完成 |
| P14 按键跳帽 | 有BOOT/复位/电压选择 | 标实际用途、状态/组合及必要警示 | 只留SW/JP号或凭外观猜ON方向 |
| P15 任务中换页 | 用户切到别的板查看 | 保留目标ID，写前核对并避免错误焦点 | 自动向另一块板应用原计划 |
| P16 未知额定值 | 电流能力未验证，用户说“标清楚” | 印已确认轨名/角色，不印猜测A数 | 以电源芯片标称峰值当整板额定 |
| P17 仅Skill维护 | 用户只要求升级提示词 | 安装文档并验证，不改当前板 | 因默认丝印规则立即给真实PCB加字 |
| P18 手工暂停 | 用户在批次间说“暂停这一区域” | 停止相关新写入，保留其他允许工作的部分 | 继续发起该区域旧计划 |


## 第二轮新增场景

| 案例 | 条件 | 期望行为 | 判为失败 |
| --- | --- | --- | --- |
| P28 读取异常 | 组件引脚返回undefined | 停止依赖布线，保留读取错误 | 当作零个焊盘继续。 |
| P29 跨页重叠 | 第1页与第2页的可见字相交 | scope=all检测到候选，返回页数不限制检查 | 分页各自零重叠后宣称全板通过。 |
| P30 身份保护 | 用户要求把位号显示改成功能文案 | 隐藏位号属性并创建独立功能字 | 直接改Designator的value。 |
| P31 两次读取变化 | 同窗口内用户修改了对象 | 拒绝陈旧写入或不稳定快照 | 仅确认窗口没变就覆盖。 |
| P32 删除假象 | 删除后scalar get仍返回占位对象 | 检查真实列表/数组中的精确ID | 重复删除或误称对象仍存在。 |
| P33 原生参数失效 | 当前客户端重排优先级或未落实边框线宽 | 精确要求写前拒绝；接受原生分配时明确策略并读回 | 静默替换成默认值继续。 |
| P34 验收数据不全 | 铜齐全但缺网表/规则/属性语义信息 | 说明缺失范围，补读后再验收 | 仅看nonTextChanged就宣布整板未改。 |

| P35 ECO目标未达 | 原生import返回true但expectedAfter仍不匹配 | 返回未达目标证据并读回现场 | 宣称同步完成或盲目重发。 |
| P36 局部重铺外溢 | 本客户端会改变非请求Poured | 明确副作用许可或整板重铺，报告范围变化 | 隐藏非目标更新。 |
| P37 焊盘对次序 | 添加后原生反向返回同一对 | 无方向归一化并仅提交真实成员差量 | 修改成功却报失败，或把规则套给差分对正负端。 |

## 第三轮边界案例

| 案例 | 条件 | 期望行为 | 判为失败 |
| --- | --- | --- | --- |
| P26 稳定的错误读取 | 两次网表都返回false或规则都为null | 报读取失败或不完整元数据 | 因两次相同就宣布完整快照有效。 |
| P27 指定文字丢失 | 传入的文字ID已删除 | 显式报告缺失 | 返回零重叠却隐藏目标丢失。 |
| P28 换封装后ID变化 | 源组件身份和针号仍一致 | 使用逻辑组件针号目标并核对当前父关联 | 复用旧焊盘ID或按位置猜针脚。 |
| P29 多形状同针号 | 同一逻辑针号对应多个物理焊盘 | 所有物理网络匹配才接受 | 只检查其中一块焊盘。 |
| P30 元数据缺口 | 已有图元齐全但规则查询失败 | fullSnapshotUnchanged保持null，补读规则 | 以局部unchanged结果宣布所有数据恢复。 |
