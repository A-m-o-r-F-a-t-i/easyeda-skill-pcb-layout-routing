# 可接线、可操作的真实丝印

完整 PCB 任务包括接口与操作件的实际丝印。根据当前引脚编号、网络、位号和真实观察面生成内容，不能按同型封装或屏幕左右位置猜针序。

普通 PH、排针、端子标接口用途、通道、逐针网络和必要的 1 脚/极性。TX/RX 以本板角色为准，同名 UART 区分所属主控或通道。供电针的电压不代表其他信号的耐压。只标已确定的功能和额定信息。

接口组名与针名分级，拥挤时用短名、分行、邻近索引和引线对应，给接插件本体和开窗让出空间。真实字体和所选工艺决定可读性，不能用缩小字号掩盖缺空间。

## MCP 操作

pcb_cleanup_components 可按需隐藏 attached Designator 的 keyVisible/valueVisible，同时保留属性和 BOM 身份。是否解锁单独选择，未修改的锁定状态保持原值。不要按文字看起来像 R1/C1 就删除普通字符串。

text 操作创建真实文字，modify 可修改选定 string/attribute 的位置、字号和显示状态。只为改丝印时不修改引脚网络，不把 Designator.value 改成功能名。独立 strings 为空不表示不存在属性文字。

## SVG 与板上输出

SVG 的位号、引脚和网络标签是观察辅助，不进入制造文件。真正的接线标识应写在正确丝印层。底面视角避免重复镜像，接口移动或 ECO 后更新受影响的旧标签。

AI 按需结合 SVG、原生视图和丝印分析检查可读性。字形 BBox 相交只是候选，不自动证明文本遮挡；没有相交也不能证明没有本体遮挡。最终报告实际完成的标识和仍未解决的对象。
