# 用户友好丝印：接口、接线和操作

## 1. 默认完成范围

完整PCB任务包含制作并验收丝印，无需用户另行提出。每个外部接口至少有用途/通道标识，PH2.0-4P、普通排针、端子、排线和其他用户需自行接线的接口必须能在板上追踪每个可接线引脚的网络。整齐的位号、空的丝印检查结果或编辑器焊盘网络浮字都不等于已完成这些标识。

布局初期预留信息带，接口变更、器件翻面和ECO后更新关联内容。功能/极性/针序正确、能读、不会误接线优先于装饰。完整 PCB 默认清除全部组件位号丝印显示，为焊盘、极性和功能文字让出空间，同时保留组件 `Designator` 属性本体、器件身份和 BOM 关联。用户明确只修改局部时遵循范围，局部变更至少修复其相关旧标识。

## 2. 标识矩阵

从当前网表、原理图接口表、元件属性、焊盘编号、器件姿态和实际使用方向建立矩阵。每条包含：接口位号/稳定关联、用途、所属主控/通道、焊盘号、实际网络、显示短名、读取视角、层、关联文字及核验状态。矩阵可在内存或已有工程资料中维护，不为每批创建文件。

**映射优先**：先确认“焊盘号→实际网络→显示短名”，再确定文字坐标。按真实封装变换获得焊盘位置，不能以屏幕从左到右、元件位号大小或同型封装推定针序。双排交错、1脚方焊盘、底层镜像和焊接面/插接面视角分别核对。

**短名规则**：`UART1_TX_EXT`可在UART1组内写TX，`I2C_SDA_S_EXT`可在从机I²C组内写SDA，实际网络名不改动。组标题必须保留能消除歧义的主从/通道信息。自动生成的`$...`网络先追踪到真实功能；无法确定时保留可核对的网络/针号并标为待判定，不编造用途。

## 3. 标识内容与使用视角

| 对象 | 默认内容 | 需要避免的歧义 |
| --- | --- | --- |
| UART接口 | 组名/通道、供电针、TX/RX/GND及其他实际引脚 | TX/RX以本板发送/接收为准，主从同号UART分开 |
| I²C/SPI | 总线与主从归属、SDA/SCL或SCK/MOSI/MISO/CS、INT及供电/地 | 多片选、备用针、信号域不能省略到无法区分 |
| CAN/RS485 | 总线通道、CANH/CANL或经器件定义核对的A/B、参考地/电源 | 不将CANH/CANL简写成UART的TX/RX，不凭习惯猜A/B极性 |
| 电源接口/端子 | 轨名、电压或已确认范围、极性、IN/OUT或双向角色 | `5V`供电不代表所有信号耐5V，不印未验证电流/耐压 |
| 舵机/编码器/电机 | 通道、信号/供电/地，编码A/B，功率输出按实际M+/M−或U/V/W | 电机半桥输出不能误标GND，未定转向不随便印正反箭头 |
| SWD/JTAG/BOOT/复位 | 调试/烧录用途、真实脚位、参考电压、RESET/BOOT等 | 调试电压感测针不自动视为供电输出 |
| 按钮/开关/跳帽 | 实际功能、档位/短接组合、默认配置或必要电压选择 | 不能只留SW1/JP1；ON方向依真实触点与电路 |
| 指示灯/测试点 | 电源/故障/运行等用途，已有测试点的网络/参考 | 控制软件未定义的LED不编造状态含义 |
| 全板 | 已确认板名/版本、装配方向、必要操作警示 | 不伪造认证、额定值、作者、URL或可长期使用的下载二维码 |

**供电与信号分开**：接口一针为5V，信号属于3V3时，针名仍标5V；在信息带合适位置补已核验的`IO 3V3`，避免被理解为5V逻辑。电流能力未经设计验证不印额定A数。

**操作视角**：主标识放在实际接线/操作面可见处，底层接口从板底的正常观察方向读字。丝印图元的层与镜像按编辑器实际规则设置，再用顶面/底面预览确认，不能凭“底层”把文字反向两次。装配后被连接器本体遮挡的功能字需要挪出，插上线束后关键用途仍尽量可见。

标准化且用户不逐线接线的高密度插座，如USB/HDMI，可保留接口用途、电源角色和1脚/方向，以明确针号索引和项目接口表支撑详细网络，不硬塞每个内部脚名破坏可读性。普通PH、排针、端子不使用这一例外，逐针标识仍要落实到板上。

## 4. PH2.0-4P完整示例

仅在真实读取确认下表映射、接口属于UART1时，使用组标题`UART1`和沿实际针位对应排列的`5V TX RX GND`。该针序是表达示例，不是PH系列的固定定义。

| 实际焊盘号 | 已核对网络 | 板上显示 |
| --- | --- | --- |
| 1 | 5V | 5V |
| 2 | UART1_TX_EXT | TX |
| 3 | UART1_RX_EXT | RX |
| 4 | GND | GND |

加入清楚的1脚标记，使分行或底面阅读时仍能追踪。若另一个同型接口为`5V GND TX RX`，按它自己的实际网络标注。不能为复用示例而改网络或把同一字符串复制到所有接口。

## 5. 拥挤时的解决顺序

1. 调整文字位置、方向和信息带，用分行的功能名＋针名、局部短名、括线或短引线对应到接口，不改变铜或针序。
2. 同接口标题集中显示主控/通道信息，逐针仅写无歧义短名。双排接口按行或针号索引对应，不把所有脚简单拍成一行。
3. 在板上同面邻近位置放完整编号引脚表，并用接口功能名和1脚锚点关联。操作面受限时在反面对应区域补图例，同时保留操作面用途/极性/方向提示。
4. 去掉全部组件位号丝印显示、无用长料号、重复封装名、装饰和冗余说明，保留必要标识及用户已有有意义文字。不得删除 `Designator` 身份属性、极性、针名、接口用途或普通说明文字。
5. 仍不可读时只回调允许移动的局部对象或利用可用边距，不先移动关键器件/改线。确需突破固定板框或机械布局时才询问取舍，明确未完成的接口，不能靠缩到不可制造的字号宣称完成。

外部文档是接线辅助，不能作为普通接口板上逐针标识缺失的默认替代。给标签加颜色或图形只起辅助作用，黑白/单色板也必须可理解。

## 6. 制造与字体

下表将设计默认值与制造依据分开。值用于普通刚性板丝印，实际选中工艺、字体输出和制造预览优先。不同官方页面存在小字极限描述差异时采用较稳妥的常规设置，不用更小极限强行挤版。

| 项目 | 本Skill设计起点 | 已核对的制造依据 |
| --- | --- | --- |
| 逐针文字高度 | 1.0～1.2 mm，空间允许取较大值 | 能力表列40mil（约1.0mm）最小字高[S1]，中文公告也要求实际字高不小于1mm[S2] |
| 接口组名高度 | 1.2～1.6 mm，按信息带一致分级 | 属于可读性选择，不是厂家强制值 |
| 笔画宽度 | 0.18～0.20 mm，结合字体检查 | 能力表/公告要求至少0.15mm[S1][S2] |
| 焊盘/开窗与丝印 | 默认预留0.20～0.25 mm，并核对实际阻焊开口 | 厂家表列焊盘到丝印至少0.15mm[S1] |
| 字间与行间 | 按真实字形留空，不只测文本中心 | 中文公告提出字符间隙大于0.15mm[S2] |

选择线性、笔画清楚的字体，小尺寸多用无歧义短名。中文和特殊符号需核对实际字形及导出结果，不能仅用一个字号数值推断可制造性。文字和标记进入真实顶/底丝印层，不能留在文档层、装配层、隐藏属性或编辑器网络显示层。

避免阻焊开窗、裸铜、接触面、板边和装配遮挡。CAM裁字可能破坏针名或极性，不能把厂家自动剪裁当作排版步骤。已有库丝印与新增标识一起检查，丝印边线亦不侵入焊盘。

## 7. 原生工具和文字来源

先分别读取独立文字`pcb_read(kind:strings)`和元件属性文字`pcb_read(kind:attributes)`，保留父器件、层、坐标、旋转、镜像、键值与可见状态。独立文字返回零项只说明当前没有这类对象，不等于位号/Value等属性文字不存在，更不等于无需丝印。

PCB MCP 2.4.8 提供 `pcb_cleanup_components`：用 `preflight → execute` 的同一 guard 解锁普通组件，并将真实组件 `Designator` 的 `keyVisible/valueVisible` 同时设为 `false` 以清除位号丝印。执行后验证 Designator 的 ID/value、普通字符串、非位号属性、组件身份和几何均未改变。独立的`easyeda-pcb-text-plan/v1`仍由`string.create/modify/delete`处理顶/底丝印独立文字，`attribute.modify`处理需要保留的已有元件属性文字。铜几何仍只写入`easyeda-pcb-plan/v2`，不能混用两种schema。

文本工具不自动生成接口名称，也不证明字形、开窗、板边、装配遮挡或制造可读性。计划中的`text`、坐标、层和父器件关系须来自本文件的标识矩阵；写入后仍完成顶/底面截图与制造预览。位号丝印清理必须使用专用接口按父组件和 `key=Designator` 识别，只关闭可见状态，不能按文字外观或坐标猜测。

复用已有正确标签，按接口关联与字段更新，保留用户文字布局意图。坐标邻近只能帮助定位，不能作为批量删除全部文字的依据。仅为改标签不改焊盘网络、丝印层上的文字不构成电气连接。

## 8. 验收门

**覆盖**：扫描所有外接接口及操作件，与标识矩阵逐项对照。记录需要标识的接口总数、已完成数、缺失对象及明确排除项。普通可接线接口需逐针对应，不能用整板字符串搜索确认某处出现过TX/GND就认为全部接口完成。

**语义**：每针实际网络与显示短名一致，主从/通道、电压角色、极性、1脚和读图视角无歧义。同型接口逐一比较，ECO后的旧标签全部失效重核。存在未知功能或映射冲突的接口不判通过。

**可读性**：顶面、底面分别预览；整板缩放检查分组，接近实物尺寸检查文字，再局部放大核对焊盘与笔画。装配后和插接后的遮挡分别检查，打印层/可见属性/导出预览一致。只读包围盒没有字形或3D信息时保留对应视觉未验证项。

**非电气影响**：纯丝印修改前后比较器件位置、焊盘网络与铜几何，确认未误改；若为标识腾空间确实移动器件，则重新走局部布局/布线验收。保存后再读关联文字，不以API返回成功或DRC为零代替标识完成。

## 数据检查与字形检查分离

先用`pcb_inspect_silkscreen`定位名义字号不足、线宽不足、可见属性字遗漏、未知包围盒与本页同层包围盒相交候选，再按真实画布和制造预览安排修改。检查阈值是任务设计目标，用户已反馈肉眼看不清时主动放大并重新排版，不能仅达到工厂极限字号就停止。

该工具的fontSizeMm是API字号换算，包围盒是原生图形外框；两者都不直接给出任意旋转和字体下的实际字高。候选相交不自动等于字形互相遮挡，未相交也不证明没有开窗或器件本体遮挡。分页检查只覆盖返回页内的文字对，合并全量包围盒后才进行跨页候选比较，视觉结论仍依实际预览。

关闭位号丝印显示不删除或修改组件自身的 `Designator`，也不把`key`或`value`伪装成接口功能字。用户确实要求器件重编号时，按原理图与PCB联动身份修改流程执行并核对BOM，不把它混入纯丝印美化。
