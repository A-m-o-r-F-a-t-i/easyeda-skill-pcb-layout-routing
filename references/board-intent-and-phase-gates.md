# 简短意图与进度记录

`approved_schematic`：已确认原理图直接执行 PCB；阶段是进度标签，不是审批门。无需建立逐引脚、逐参数、逐封装或样机性能证据表。

## 最小记录

只记录目标身份、给定板框/孔位/面别、布线规则、关键网络回路、已改对象、下一动作和真实工具阻断。可使用 [意图模板](../templates/board-intent.yaml) 和 [阶段模板](../templates/stage-state.yaml)，但填表不是写板前提。

不设置 `preLockChecks`、`unlockedActions`、逐次续作帧或“并行补齐电气证据”要求。没有资料的高度、磁气隙、热和器件额定值不进入 PCB 待办；保持用户提供的输入，不自行验证或改变。

## 旧任务阶段对照

| 阶段 | 工作 |
| --- | --- |
| S0 | 唯一目标和单位 |
| S1 | 首次导入或实际 ECO，同步好的板直接跳过 |
| S2 | 板框、孔槽、给定禁区和层分工 |
| S3 | 模块布局与困难通道试布 |
| S4 | 关键供电回路与信号 |
| S5 | 剩余网络 |
| S6 | 铺铜、回流、丝印和要求的测试点 |
| S7 | 布线铺铜丝印完成后，集中 PCB DRC 和连接检查 |
| S8 | 保存并导出对应生产文件 |

状态用 pending / in_progress / completed 即可；局部工具阻断单独记对象。不要求前一阶段全板完结才画下一模块，不在模块布局后自动运行整板 DRC。

## 变化处理

自己移动元件后更新本批位置和焊盘缓存，不使整板网表失效。用户改位置就保留新位置、重规划相关铜；用户改原理图就做实际 ECO。只有受影响的对象和最终导出需要更新，不退回 S0 重审。

模块结束、故障或任务切换时写一次断点，普通读取和成功小批操作不重复写记录。断点至少保存下一项真实 PCB 操作；工具恢复后只对账不确定对象，然后接着画。
