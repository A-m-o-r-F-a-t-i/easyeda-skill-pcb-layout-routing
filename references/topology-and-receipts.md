# 铜区拓扑与执行回执

## 1. 读取既有铜连接

`pcb_read` 的 topology 模式和 `pcb_audit_geometry` 的 topology 检查使用同一物理铜模型。例子中的位号、网络和坐标必须换成实际对象，所有几何量为 mil。

```json
{
  "kind": "topology",
  "nets": ["PWR", "OUT"],
  "paths": [{"net": "PWR", "from": "Q1.5", "to": "C1.1"}],
  "sections": [{"net": "PWR", "layer": 2, "from": [100, 0], "to": [100, 200]}],
  "limit": 100
}
```

结果包含网络连通分量、焊盘归属、没有已建模焊盘接触的铜岛、过孔外径和孔径。paths 返回在现有铜上的路径、最少换层数、可用同层通路、换层对象及模型内必经孔。必经孔表示移除该孔后指定端点在模型中断开；它不表示该孔的载流能力一定不足。并联孔的电流分配不由拓扑推导。

sections 报告给定直线与该网络铜面的相交区间及长度。它只代表这条截面，不是自动寻找的全板最小铜颈。横截面方向和测试位置由 AI 决定。

可选 excludeIds 在只读模型中排除明确对象，再计算路径。除当前主干端点外，还要考虑受影响分支与返回连接，避免清理短线时切断必要支路。该操作不删除 PCB 对象，不输出无条件的“可安全删除”。铜岛还可能用于屏蔽、散热或后续连接，必须结合实际范围处理；没有接触已建模焊盘的铜分量不自动等于无用铜。

## 2. 覆盖范围

模型处理已枚举的直线、圆弧、常规和已知坐标系异形焊盘、通孔、实体铜，以及单位已经确认的实际成铜。铺铜边界本身不参加导通；复合孔洞和已知物理钻孔从铜中扣除。盲埋孔层跨度、未知焊盘坐标、未确认成铜或枚举失败会列入 coverage，不能把缺失数据解释为不存在。

曲线采用 curveToleranceMil 指定的弦误差离散化，默认 0.02 mil，接触容差也会单独返回。边界附近的相切和窄间隙需要结合原生 DRC/实际视图。分析不读取铜厚或温升目标，不给出额定电流、阻抗或仿真合格结论。

局部网络选择只筛选网络，不代表局部区域之外没有回路。当前拓扑读取整板一次后分析选定网络，输出可分页保留。依照返回 coverage 判断结果范围，不能将 PARTIAL 写成全板通过。

## 3. 提交与查询回执

`pcb_edit` 可携带 requestId。ID 与完整请求内容绑定，同 ID 重复调用返回原结果，同 ID 不同内容返回 REQUEST_ID_CONFLICT。新的修改使用新 ID。未提供 ID 时由 MCP 生成 receiptId；响应遗失后可通过近期列表找回。

```json
{"kind": "receipt", "receiptId": "power-group-edit-01"}
```

```json
{"kind": "receipts", "offset": 0, "limit": 30}
```

`refresh=true` 只读尝试获取同一文档内的原生执行日志，不重新执行操作。回执包含 created/modified/deleted 对象引用、wrotePcb、保存结果、各操作状态及 nextIndex。wrotePcb=null 表示未知；saved=false 与已确认修改成功可以同时出现。

持久意图写入成功后才派发编辑。同一持久目录内的重复请求不会再派发，但原生编辑不是数据库事务。编辑器重启可能丢失内存日志，主机缓存清理可能移除本地记录；这种情况下保留未判定并读取实际对象，不盲目重放。

## 4. 原生拓扑变化后的读取

　　执行成功也可能触发编辑器自动分段，回执中的 created/modified/deleted 不保证枚举全部关联变化。移件、移孔或改铜后，先结合回执定向读取受影响网络的新焊盘、线段、支路与返回连接，再使用当前 ID 继续修改；不沿用已失效的旧 ID，不把保留结果当实时板面。

　　只刷新实际受影响部分，无关网络和未变结果继续复用。接口没有合并筛选时按当前 Schema 分别读取，不构造不存在的参数。未知结果沿用同一回执查询与实际对象核对，不自动重放整批，不通过整网删除清理局部残留。

## 5. 本地数据配置

EASYEDA_PCB_STATE_DIR 是可选配置，指定回执的持久目录根。未设置时可使用宿主提供的 PLUGIN_DATA，最终默认当前用户目录下的 `.easyeda-pcb`。EASYEDA_PCB_ARTIFACT_DIR 可指定 SVG 和保留结果目录。配置值和运行记录不进入 Skill 包或 Git 仓库。

这些能力只帮助模型理解铜连接与实际执行结果。布局、路径、宽度、过孔数量、清理对象和分析时机仍由模型决定。
