# 布局：把已有网络变成可布线的整组通道

采用 approved_schematic，信任既有原理图和封装。直接依据当前作图数据放置，不重新复核器件针脚、参数或高度，不把三维资料缺失变成布局阻断。完整流程见 [模块布局与布线](placement-routing-closure.md)。

先落实用户给定的板框、孔位、禁区和面别。贴片外部接口靠板边，真实插口朝外；主电路留在指定面，普通器件未锁定。用当前封装轮廓避免已知碰撞，保留安装工具、线束和丝印空间，不先建立完整装配审查模型。

按功能链而非器件种类排队：主控→串阻→保护/收发器→接口，供电入口→保护→储能→转换→负载。串联器件两侧虽然网络名不同，仍是同一信号链。旋转主控让关键接口直接扇出，不为了位号正立旋转芯片。

去耦围绕供电脚和地返回，反馈围绕反馈端和输出取点，驱动与自举外围跟随服务芯片。同网电容按既有原理图分区区分入口储能、本地旁路和驱动去耦，不重新检查容值或总容量。排阻只优化位置和旋转，不交换已确认通道。

给密脚保留直出段、倒角和落孔空间，别让去耦、排阻或通孔阵列封死整排引脚。电源出口留足铜宽，地参考不被无意义分区切碎。接口和主控都能在用户允许范围内为关键通道微调。

在落第一根线前，以网络组为单位画出入口、出口、瓶颈、允许层、参考/回流和功率铜骨架。直线通道至少容纳各线宽、相邻间距与两侧退让，拐角、扇出和过孔另留余量；先为最受约束的组保留通道，不让单根最短线占满整组唯一出口。

一个模块读完就落位，困难网络组用真实规则试布，不需要先做多方案评分表。缩板或试布导致后续只能钻缝、反复折返、过孔拥挤、铜颈或无出口，就调整该模块、重分整组通道或局部拆线，不缩小电源和制造间距。每组只做区域回看；布局阶段不主动运行整板 DRC，布线铺铜丝印完成后集中检查。

已有铜的元件用 replan，处理相关旧铜后重布。消费工具独立读回；缺少新焊盘坐标才读本批，不重新审查引脚。用户中途改动保留，相关线路随之调整，不用旧计划覆盖人工位置。
