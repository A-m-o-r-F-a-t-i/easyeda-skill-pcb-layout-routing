# PCB 直接执行模式

## 已确认原理图到 PCB

默认 `approved_schematic`。锁定目标与单位，空白板导入既有原理图，已有板直接续作。信任既有器件、参数、引脚和封装；不重新检查电气合理性，不查气隙、高度或器件手册，也不留到交付前补审。

正常循环：

```text
取本模块作图数据（缓存可用就不重读）
→ 按实际连接形成网络组并规划通道/功率铜骨架
→ 决定位置/朝向或明确该组走线路径
→ prepare → execute
→ 用执行器独立读回更新本批缓存
→ 回看本组、邻域和剩余网络出口
→ 下一个模块/网络组
```

`prepare`负责计划校验和状态绑定，普通操作不必先单独 `validate`。成功回执已包含独立验证时不再额外跑 pinmap、快照或 DRC；后续布线缺少新焊盘坐标才补读本批端点。模式与字段见 [操作速查](operation-recipes.md)。

## 布局与局部重排

按给定板框、孔位、面别与接口朝外要求放置。先完整功能块，再局部压缩和旋转；普通组件保持可调整且不默认锁定，旧对象误锁时随下一次修改解除。落第一根线前先为整组确定入口、出口、瓶颈、层、参考/回流和通道余量；后续只能钻缝、折返或挤出铜颈时，回退占道的早期线路或调整局部模块。已有铜的元件移动用 replan，清理相关旧铜后重布；未布铜用 unrouted。不要把一个元件移动升级为全板预检。

## 供电与信号

先安排供电去程/返回和开关电流小回路，再安排采样、栅极、自举、时钟、接口，最后普通信号。焊盘层上起线，换层用实际过孔；按项目给定尺寸使用宽铜及回流，不重新审查原理图选型或参数。

## DRC 时机

初始化和布局不主动运行整板 DRC。普通保存明确 `save:true, runDrc:false`。每个网络组完成后只回看该组的端点、通道、铜颈、换层回流和剩余出口；布线中遇到明确短路或工具指出的间距问题，只处理该区域，不为尚未完成的飞线和摆放运行全板错误树。

布线、铺铜和丝印全部完成后，集中运行最终原生 DRC 与连接检查；修正实际 PCB 问题，再保存导出。不自动调用组合验证工具作为每个工作块的门槛，也不改变编辑器实时 DRC 开关。

## 原理图变更与丝印

只有首次导入或用户实际修改原理图时使用 ECO，沿用给定电路而非重新设计。导入后刷新变化组件/焊盘的 ID 与网络，保留独立孔槽、端子和用户改动，并执行 `pcb_cleanup_components`解除普通组件锁定、关闭组件 `Designator` 的丝印显示。丝印写当前端点的真实网络功能；位号清理保留 Designator 身份和 BOM 关联。

## 错误与续作

失败只定位错误操作；结果未知时读实际对象，保留成功前缀，只创建剩余后缀。最多两次轻量连接探测和一轮定向修复，恢复后执行原 PCB 动作。全局连接失效时如实报告，不长时间被动等待或声称换区即可继续。

需要修 Skill 时只修改相关规则并做文档/示例测试；不要为证明文字更新，改动正在工作的 PCB，也不要重编译未变的 MCP。详细最终交付见 [检查导出](inspection-and-release.md)。
