# 原生 DRC 数据判读

pcb_save_and_drc 是按需分析工具。布局成形、关键孔位或铜连接改变后及最终收尾，应取得覆盖当前改动的原生 DRC；同一批相关操作可以合并检查，普通编辑不逐次插入 DRC，也不要求按固定阶段解锁。候选孔位先根据各相关层与孔槽几何计算，DRC 用于验证，不用它反复试探放孔位置。

## 完成状态

save 与 runDrc 分别选择。普通保存可用 runDrc=false。运行中的原生检查返回 RUNNING 和 drcJobId，使用同一 jobId、save=false 继续读取。COMPLETED 与 drcVerified 表达真实运行状态，drcErrorCount/drcSummary 是完整数量，drcItems 为分页明细。

失败、超时、作业丢失、空明细页都不能解释为零违规。已有结果可以按页展开，不重复创建作业。修改后根据变更与报告覆盖范围取得有效结果，历史零错误不能冒充修改后的最新检查。发现条数不等于独立缺陷数，同一对象或位置可能产生多项规则发现。

## 判断对象

| 数据 | AI 的处理依据 |
| --- | --- |
| 不同网络短接、实际孔/铜/元件冲突 | 查看具体对象和位置，先修复本次产生的真实冲突再扩大修改范围；布局阶段跨元件焊盘重叠不得忽略 |
| 同网络焊盘间距 | 结合网络和对象归属判断是否为可接受融合，不以同网理由掩盖跨组件物理冲突 |
| 可信封装内部报告 | 区分同一未修改库封装内部情况和延伸到外部对象的真实问题 |
| 未连接 | 尚未布线的连接在施工期作为待办；本次修改破坏已有必要支路或返回时先恢复；交付时完成或明确保留原因 |
| 信息不足 | 读取相关对象，保持未知，不自动忽略 |

允许保留的原生报告记录具体理由，不能称为原生零错误。MCP 返回数据，不批准布局、停止后续编辑或强迫重跑。不得通过静默改网、删除必要对象或放宽既定规则使报告消失。
