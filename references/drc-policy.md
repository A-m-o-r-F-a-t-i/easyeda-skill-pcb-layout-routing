# PCB 原生 DRC 阶段与判定规则

适用 `approved_schematic`。原生 DRC 是 PCB 作图的必要检查，不是数据手册、器件选型、引脚定义、外围参数或样机性能复审。普通小批写入仍依靠目标保护和独立读回；整板 DRC 在能改变下一步动作的阶段运行。

## 1. 必须执行的阶段门

统一调用 `pcb_save_and_drc(save=true, runDrc=true)`。调用必须确认 `drcVerified=true`；执行失败、返回类型异常或明细不可读都不是通过。

| 阶段 | 运行时机 | 本阶段必须处理 |
| --- | --- | --- |
| `LAYOUT_DRC` | 板框、孔槽、禁区和成体系布局完成后，正式布线前；重大机械或大范围布局变化后重跑 | 优先核对间距报告中的对象归属，修正不同组件焊盘重叠、独立 PTH/NPTH/大过孔侵入元件焊盘，再处理实体、板边、孔槽、禁区、层面和制造间距 |
| `ROUTING_DRC` | 关键供电/大电流/高速/敏感回路完成后，以及整板布线完成后；两者为同一工作块时可合并 | 不同网络短路/间距、线宽/孔径、板边/禁区、关键铜与过孔问题；施工期未布线可暂缓 |
| `POUR_DRC` | `pcb_rebuild_pours`产生新的实际铜后；后续铜边界、孔位、走线或器件变化影响填充时重跑 | 覆铜短路/间距、孤立或错误连接相关报告、铜到板边/孔/禁区问题 |
| `FINAL_DRC` | 最终重铺、位号清理、功能丝印和保存完成后，任何生产文件导出前 | 所有阻断项；未布线在此阶段必须清零 |

普通保存使用 `runDrc:false`。单颗移动、单根走线、每个网络组或每一小批写入后不重复整板 DRC；布局轮次先用执行期 `padOverlapGate` 清除跨对象焊盘重叠，整体布局成形后再运行 `LAYOUT_DRC`。到上述里程碑不得跳过。若两个相邻里程碑之间没有任何会影响对应几何、网络或铜的变化，一次原生检查可同时登记两个阶段；修改后不能复用旧结果。

## 2. DRC 项目的判定优先级

按下列顺序判定，前项覆盖后项：

1. **跨对象物理重叠：阻断。** 不同组件焊盘互相重叠，独立 PTH/NPTH/接线焊盘或过孔侵入元件焊盘，焊盘侵入另一组件实体，或组件实体/装配外形冲突，布局阶段立即修正。即使对象属于同一网络，也不得使用“同网间距”豁免。
2. **明确制造或连接错误：阻断。** 不同网络短路/间距、铜到板边/孔槽/禁区、非法孔径/环宽、错误层面、真实铜冲突等必须按当前阶段修正。
3. **同网络焊盘间距：可豁免。** 只有原生结果确认相关焊盘属于同一网络，且不存在跨组件物理重叠、板边、孔槽、禁区或装配冲突时，才记为 `waived_same_net_pad_clearance`。
4. **可信库封装内部报告：可豁免。** 所有相关对象必须属于同一组件、同一未修改的嘉立创/EasyEDA 官方库封装，且没有扩展到外部铜、其他组件、板边、孔槽或禁区，才记为 `waived_trusted_footprint_internal`。自建、编辑过或来源不明的封装不能自动豁免。
5. **未布线：分阶段处理。** 在布线尚未完成的 `LAYOUT_DRC`、中间 `ROUTING_DRC` 或 `POUR_DRC` 中可记为 `waived_unrouted_in_progress`；宣布整板布线完成后及 `FINAL_DRC` 中属于阻断项。
6. **无法确认：未决。** 对象归属、网络、规则含义或原生数据不足时记为 `unresolved`，补读相关对象后再分类，不能自动忽略。

## 3. 结果记录与修复

每次阶段结果至少记录：阶段 ID、DRC 是否真实执行并验证、原始总数、`blocking`、`waived`、`unresolved`，以及每个豁免项的原生标识、规则、对象和理由。`LAYOUT_DRC` 的间距项先解析双方对象 ID、父组件和网络；无法确认归属时保持 `unresolved`。原生报告仍有豁免项时只能称“阶段通过并带明确豁免”，不能称“DRC 零错误”。

“忽略”不允许通过关闭实时/批量规则、放宽间距、改网、隐藏或删除必要对象来实现。`PAD_OVERLAP_BLOCKED` 或 `padOverlapGate=BLOCKED/UNVERIFIED` 表示当前布局轮未完成，不得绕过或开始下一轮；修正后重新执行本轮。阶段 DRC 阻断项修复后重跑对应阶段，布局重叠清零后才可正式布线。只有 `blocking=0` 且 `unresolved=0` 才通过当前阶段，`FINAL_DRC` 还要求未布线为零。

## 4. 与电路审查的边界

DRC 只处理当前 PCB 文档中的几何、连接和制造规则。它不要求查找器件数据手册，不重新验证额定值、容值、针序、NC、驱动能力、磁气隙、封装高度或原理图外围是否正确；这些内容只有用户明确委托电路审查时才进入其他工作流。
