# 已确认原理图 → PCB 执行提示词

原理图、器件参数、封装和针序已经确定，请按现有设计直接完成 PCB。采用 approved_schematic 模式，不重新审查电气性能、选型、NC、外围参数或引脚分配，不查数据手册验证气隙、磁钢、封装高度，也不要把这些事项列为稍后补审或生产阻断。

工作重点是给定板框、孔位、面别和接口方向，以及网络关系、供电去程与返回、开关小回路、去耦、自举、Kelvin 和布线通道。贴片外部接口默认靠板边且插口朝外；主电路留在指定面。信任源电路，不交换针序或改料来迁就布局。

锁定当前 PCB，必要时导入原理图。只读取下一批作图需要的对象旧值、封装轮廓和焊盘网络坐标，已有数据直接复用。拿到数据后立即放置或走线，普通元件保持可调整，难走就局部旋转或重排。不要全器件属性遍历、重复 pinmap 或反复生成审批表。

使用显式计划 prepare → execute，并消费工具已经完成的独立读回，不盲目重放失败批次。普通保存 runDrc:false；布局阶段不主动跑整板 DRC，布线途中只处理明确局部问题，布线铺铜丝印完成后再集中最终 DRC、连接与生产文件检查。禁止整板自动布局、自动寻路和自动布线。

工具真的出错时只修该问题，保留已成功对象，恢复后继续原板上动作。记录仅保留目标、阶段、已改对象、下一动作和真实阻断；工具修复/验证不算 PCB 进展。只有实际未完成的 PCB 或文件问题才影响交付，不新建上游电路和三维参数调查任务。
